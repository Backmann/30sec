# 30sec

Платформа интеллектуальных турниров, построенная вокруг того, чего не умеют
автоматические квизы: **ответы судит человек.** Игрок отвечает своими
словами, а ведущий решает, засчитывать ли.

Продакшн: [30sec.org](https://30sec.org) · закрытая бета

**Полное описание — в английской версии: [README.md](README.md).**
Там разобраны механика матча, возможности для игрока, зрителя и ведущего,
архитектура, безопасность и инженерные тонкости. Здесь — короткая справка
по-русски.

| Репозиторий | Роль |
|---|---|
| [`30sec`](https://github.com/Backmann/30sec) | API, игровой движок, БД, realtime, инфраструктура |
| [`30sec-frontend`](https://github.com/Backmann/30sec-frontend) | Веб-клиент |

## Коротко о механике

Матч из **23 вопросов**, идёт до **12 очков**. Каждый вопрос даёт ровно
одно очко: игроку, если судья засчитал ответ, системе — если отклонил.
Неответ считается отклонением.

На вопрос: **20 секунд** на чтение, **30 секунд** на ответ, затем
судейство. Ведущий может добавить 10 секунд к чтению.

Все решения судьи копятся на сервере и раскрываются **одним событием**,
когда оценены все ответы. До этого момента никто не видит ни чужих
ответов, ни правильного. Счёт 11:11 — решающий вопрос.

Зрители смотрят тот же матч и могут отвечать для себя; их ответы хранятся
отдельно и на матч не влияют.

## Стек

**Бэкенд:** NestJS 10, TypeScript 5.7, Prisma 6, PostgreSQL 16, Redis 7,
BullMQ, Socket.IO, argon2.
**Фронтенд:** Next.js 14 (App Router), React 18, Tailwind 3, Zustand,
socket.io-client 4.
**Инфраструктура:** Docker Compose, nginx, Cloudflare, R2 для картинок.

Интерфейс на трёх языках: русский, английский, немецкий.

## Что важно знать при работе с кодом

- **Схема БД меняется только сырым SQL.** `prisma migrate reset` уничтожит
  продакшн-данные.
- **Файлы на диске — не файлы в контейнере.** После правки нужен
  `docker compose build`, иначе выполнится старая версия. Особенно опасно
  для `prisma/seed.ts`: сид перезаписывает справочные таблицы.
- **После пересоздания контейнера API нужен reload nginx** — иначе 502,
  потому что nginx держит в кеше прежний адрес контейнера.
- **API не пишет журнал HTTP-запросов** — факт запроса виден в логах nginx.
- **Дефолтных паролей в коде нет.** Стек не поднимется без
  `POSTGRES_PASSWORD` и `REDIS_PASSWORD`, сид не создаст админа без
  `ADMIN_PASSWORD` от 12 символов. Репозиторий публичный, и любая
  заглушка была бы известным всем доступом.
- **Секреты только в `.env` на сервере** (`chmod 600`), в git и в истории
  git их нет.

Подробности, включая устройство ограничения частоты запросов, восстановление
живого матча после перезапуска и список того, что пока не реализовано, —
в [README.md](README.md).
